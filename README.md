
# Electric Vehicle Data Analysis Dashboard – Tableau

## 📌 Project Overview
This project presents an interactive Electric Vehicle (EV) Data Analysis Dashboard developed using Tableau Public. The dashboard explores electric vehicle registration data to identify adoption trends, manufacturer performance, vehicle distribution, and clean alternative fuel vehicle eligibility.

## 🎯 Project Objectives
- Analyze electric vehicle adoption across model years.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Identify leading EV manufacturers and popular vehicle models.
- Visualize the geographic distribution of electric vehicles by state.
- Analyze Clean Alternative Fuel Vehicle (CAFV) eligibility.

## 🛠️ Tools and Technologies
- Tableau Public
- Data Visualization
- Data Analysis
- Interactive Filters and Dashboards

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Vehicles
- Average Electric Range
- BEV Percentage
- Total PHEVs and their percentage contribution

### 2. Total Vehicles by Model Year
An area chart displays the number of electric vehicles across model years to highlight adoption trends over time.

### 3. Total Vehicles by State
A geographic map visualizes the distribution of electric vehicles across different US states.

### 4. Top 10 Total Vehicles by Make
A horizontal bar chart compares vehicle manufacturers based on the number of vehicles represented in the dataset.

### 5. Total Vehicles by CAFV Eligibility
A doughnut chart compares vehicles classified as CAFV Eligible, CAFV Not Eligible, and CAFV Unknown.

### 6. Total Vehicles by Model
A detailed table presents vehicle models, manufacturers, EV types, and their contribution to total vehicles.

### 7. Interactive Filters
Users can filter the dashboard by:
- EV Type
- Model
- State
- Clean Alternative Fuel Vehicle (CAFV) Eligibility

## 💡 Key Analytical Insights
- Compare vehicle adoption across model years.
- Identify manufacturers with higher vehicle counts.
- Explore state-wise EV distribution.
- Compare BEV and PHEV representation.
- Understand CAFV eligibility categories.
